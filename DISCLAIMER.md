# File operations

Review the selected folder and deletion choices before confirming. Visual similarity can include different photographs. Marking a photo does not delete it. Recycle-bin recovery depends on the operating system and deletion method; permanent deletion cannot be undone by AlbumDone. Keep independent backups of important photos.
