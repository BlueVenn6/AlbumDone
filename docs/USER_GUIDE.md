# AlbumDone desktop guide / 桌面操作说明

Choose a local photo folder. The three workflow cards use the selected folder.

Duplicate review: choose a quantity and start. The group count counts actual photos; the large image previews a selected member of that group. Clicking a thumbnail changes the preview. “Keep only this” changes the keeper; “Keep all” cancels that group's deletion choices. Review the deletion total and confirm before files are moved. “Choose batch” returns to quantity selection; completed no-match batches still advance folder progress. Separate batches compare photos within each batch; choose all from the beginning to compare the whole folder.

Manual review: choose a quantity, then use Previous/Next buttons or keyboard shortcuts to browse. Browsing does not mark a photo as reviewed. Mark keep/delete and undo if necessary. Marking a photo does not delete it. Review the completion summary, then confirm deletion or retain those photos. Choose another batch to continue through the folder. A truly interrupted review can be continued.

Year in Review: choose the past twelve months or last year. Generate twelve actual month cards; empty months receive quotes. Choose another photo from that same month's candidates, or change a quote. Save exports the current choices to a local JPG, with an action to open it.

Use the sidebar language selector to switch among fifteen languages. A folder name or filename remains the original user-provided text. Photos with unavailable formats, missing files or read errors must be checked separately.

选择本地文件夹后，三个功能入口都针对当前文件夹。

自动去重：选择数量后开始。大图是组内预览，不增加照片数量。点击缩略图切换预览；“只保留这张”更换保留对象，“全部保留”取消整组的待删除选择。检查删除总数并确认后才执行。完成后可回到数量选择，零重复结果也会保存检查进度。不同批次分别比较；需要全文件夹比较时，重新开始并选择全部。

手动筛选：选择数量，用上一张/下一张按钮或键盘操作浏览，浏览不会自动标记为已审阅。可逐张或网格标记，支持撤销。标记不等于已经删除。完成后检查汇总并确认，或保留照片，再选择下一批。只有确实中断的任务才提供继续入口。

年度回顾：选择过去十二个月或上一年，生成实际月份卡片。可更换同月照片和空月份寄语。保存时导出当前选择的本地 JPG，可直接打开。

左侧可切换 15 种语言。用户原本的文件夹名和文件名保持原样。缺失、损坏或格式不支持的照片需要另外核查。
