# Desktop privacy / 桌面版隐私说明

Applies to AlbumDone desktop 0.2.1 without AI features.

Photo scanning, thumbnails, similarity analysis, manual decisions and year-review rendering run locally. This desktop version contains no AI provider integration, OCR, account sign-in, advertisements, analytics SDK or automatic photo upload. Selecting a folder allows the application to read supported photos in that folder. Local data includes recent folder paths, a photo index, thumbnails, review checkpoints, logs and exported JPGs. These are stored in the application data directory; originals remain in the selected folders until a deletion is confirmed.

Deleting prefers the operating-system recycle bin, with a local fallback if necessary. Permanent deletion is a separate confirmed action. Recovery depends on the actual deletion method and system state; the application does not promise a fixed retention period. Uninstalling is not a substitute for clearing local review/export data or the system recycle bin.

The retained local-network server utility does not start automatically; no cloud photo service is provided. External actions such as opening a file use the operating system. Dependency downloads, GitHub and software installation are separate from the photo workflows.

This document describes application behavior. App-store privacy declarations and any policy published on an external website must be checked against the final binary and distribution configuration.

适用于 AlbumDone 0.2.1 无 AI 桌面版。

照片扫描、缩略图、相似度分析、手动选择和年度回顾渲染均在本机执行。本桌面版不包含 AI 服务商接入、OCR、账户登录、广告、统计 SDK 或自动上传照片。选择文件夹后，应用可以读取其中支持的照片。本地保存的资料包括最近文件夹路径、照片索引、缩略图、任务进度、日志及导出的 JPG。原照片在确认删除之前仍位于所选文件夹。

删除优先使用系统回收站，必要时使用本地备用回收目录。永久删除需要单独确认。能否恢复取决于实际删除方式和系统状态，本应用不承诺固定保留天数。卸载应用不会自动清理所有导出文件或系统回收站。

保留的本地网络服务工具不会自动启动，应用不提供云端照片存储。打开文件等操作交由操作系统处理。依赖下载、GitHub 和安装过程不属于照片处理流程。
